
# ThesisHub

A full-stack social platform for sharing, discussing, and evaluating structured stock-market investment theses.

## Project Overview

ThesisHub makes investment ideas easier to understand, compare, and track through a consistent post format.

Each post includes:
- A one-sentence investment thesis
- One or more stock tickers
- Required conviction level
- Automatically generated YTD/1Y stock chart
- Optional price targets, catalysts, risks, strategies, and supporting evidence

## Planned Features

- User authentication
- Public thesis feed
- Create, edit, and delete posts
- Five sentiment reactions
- One editable reply per user per post, with public edit history
- Popularity-based sorting
- Structured search and filters
- Free external stock-market API integration

## Planned Tech Stack

- Frontend: React, Vite
- Backend: Node.js, Express
- Database: PostgreSQL, Prisma
- Authentication: JWT, bcrypt
- Version Control: Git, GitHub
- Development Environment: Antigravity IDE
